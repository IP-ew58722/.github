<h2>住宅网络和机房网络的根本差别</h2>
<p>机房网络是「插上就通」，住宅网络则要经过一条真实家庭宽带的完整链路：入户光纤、光猫、路由器、拨号、内网分配。这条链路上任何一环配置不当，都会让出口属性、稳定性、可达性出问题。所以搭建住宅环境，重点不在服务器软件，而在这条链路。</p>
<p>下面按物理到逻辑的顺序，把住宅侧配置讲清楚。</p>

<p>最常见的坑是光猫既做路由又做 NAT，导致外部无法直接访问内网设备。解决方式有两种：改桥接由自己的路由器拨号，或在光猫上做端口映射。</p>

<h3>改桥接前要准备什么</h3>
<p>需要运营商的宽带账号与密码，通常在安装单或光猫管理页里能看到。改桥接后光猫不再拨号，若忘记账号密码会断网且难以恢复。改之前先把参数抄下来。</p>
<h3>端口映射与 DMZ 的区别</h3>
<p>端口映射只开放指定端口，安全边界清楚；DMZ 把内网某台设备完全暴露，风险高。优先用端口映射，不要图省事开 DMZ。</p>

<h2>第二步：内网规划</h2>
<p>把网段规划清楚，避免与需要访问的目标网段冲突。常见做法是选一个不常用的私网段，并固定设备的地址分配，不要让关键设备用动态地址，否则重启后地址变化会导致配置失效。</p>
<p>固定方式有两种：在路由器上做地址绑定，或在设备上配静态地址。前者集中管理，后者不依赖路由器。建议前者。</p>

<h2>第三步：拨号与链路参数</h2>
<p>PPPoE 拨号需要账号密码，注意两点：一是 MTU，住宅 PPPoE 常见需要调低，否则大包被丢弃；二是断线重拨，线路抖动后要能自动恢复，否则会长时间掉线。</p>
<p>把「自动重拨」和「断线检测」两项开起来。这两项决定了长期在线的稳定性，比带宽数字更重要。</p>

<h3>关于地址变化</h3>
<p>住宅宽带的地址可能因重拨而变化。若业务需要固定地址，必须确认服务商是否提供固定地址，或是否通过其他方式保持出口不变。这一项要在采购时就问清，不能事后补救。</p>
<h3>关于上行</h3>
<p>住宅宽带上行通常远低于下行，且高峰期会被运营商限速。做上传、推流类业务时，先用实测工具测出真实上行，再据此定业务量。按标称带宽规划，几乎一定不够用。</p>

<h2>第四步：设备与散热</h2>
<p>住宅环境的运行条件不如机房。夏季高温、供电波动、灰尘，都会导致设备不稳定。实际经验里，很多「莫名掉线」最终定位到散热或电源问题。</p>
<p>做法很简单：设备放在通风处，加一个稳定的电源，必要时加小型风扇。成本很低，效果明显。</p>

<h2>第五步：验证与记录</h2>
<p>验证四项：出口地址与归属正确、上行速度达标、连续在线时长稳定、外部端口可达。四项都记录基线值，后续出现偏差时才有对比依据。</p>
<p>记录建议用表格，包含时间、出口地址、延迟、上行速度、异常描述。连续记录一段时间，规律自然出现。</p>

<h2>常见问答</h2>
<h3>住宅网络能做服务器吗</h3>
<p>可以，但受限于上行带宽与地址是否固定。轻量服务完全够用，高并发或大流量场景不适合。</p>
<h3>为什么外部访问不到内网设备</h3>
<p>多数是 NAT 未做映射，或运营商做了上层 NAT。前者自己可以解决，后者需要向运营商申请或改用其他方案。</p>
<h3>重启光猫会换地址吗</h3>
<p>可能会。需要固定地址的业务，要确认服务商的保号机制，避免重启导致地址变化。</p>
<h3>住宅网络需要 UPS 吗</h3>
<p>有条件建议加。断电导致的非正常关机容易损坏设备与数据，一个小容量 UPS 就能避免大部分问题。</p>
